# Drupal Security & IAM Module Suite

A collection of 12 open-source security and IAM modules for Drupal 11 / Drupal CMS 2.0.

## Modules
1. HIBP Password Guard — Compromised password detection
2. API Flood Guard — REST/JSON:API brute-force protection  
3. CSP Wizard — Content Security Policy autopilot
4. Session Sentinel — Unified session security
5. Paranoia Reborn — PHP execution lockdown
6. SBOM Sentinel — Supply chain security
7. Passkey Forge — Enterprise FIDO2 passkeys
8. Zero Standing Privilege — JIT role elevation
9. SCIM Bridge — SCIM 2.0 server for IdP provisioning
10. API Key Vault — Machine identity lifecycle
11. Behavior Beacon — UEBA anomaly detection
12. Compliance Command Center — Multi-framework GRC dashboard

## Requirements
- Drupal 11.x or 10.4+
- PHP 8.2+
- Drupal CMS 2.0 compatible

## Installation
Place modules in your Drupal installation's modules/custom/ directory and enable via drush en [module_name] or the Drupal UI.
